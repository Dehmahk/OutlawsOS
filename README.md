# OutlawsOS

OutlawsOS is the Eastern Kingdoms Outlaws edition of GuildOS, a guild manager addon for World of Warcraft: Forever and Retail.

It's a fork of GuildOS by Chehul (danielcosta42). The original GuildOS code is MIT licensed; the Outlaw changes are not, and need Victoria's permission to modify or redistribute (see `OutlawOS/LICENSE.txt`). The original project is at https://github.com/danielcosta42/GuildOS. The original copyright notice is kept in `OutlawOS/LICENSE.txt`.

## Install
1. Download or clone this repo.
2. Copy the `OutlawOS` folder into `World of Warcraft\_retail_\Interface\AddOns\` (or the Forever equivalent).
3. Updating from GuildOS (1.40 or older)? Delete the old `GuildOS` folder first, and copy `WTF\Account\<your account>\SavedVariables\GuildOS.lua` to `OutlawOS.lua` in the same folder before you log in.
4. Fully restart WoW. `/reload` is not enough.
5. Type `/gos` or `/outlawos` to open the addon.
