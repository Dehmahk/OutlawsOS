# OutlawsOS

OutlawsOS is the Eastern Kingdoms Outlaws edition of GuildOS, a guild manager addon for World of Warcraft: Forever and Retail.

It's a fork of GuildOS by Chehul (danielcosta42), released under the MIT License. The original project is at https://github.com/danielcosta42/GuildOS. The original copyright notice is kept in `GuildOS/LICENSE.txt`.

## Install
1. Download or clone this repo.
2. Copy the `GuildOS` folder into `World of Warcraft\_retail_\Interface\AddOns\` (or the Forever equivalent).
3. Fully restart WoW. `/reload` is not enough.
4. Type `/gos` to open the addon.
